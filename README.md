# PS3-Project Cerberus
Cerberus is an open-source Resident Evil emulation project targeting the PlayStation 3.

Using PSL1GHT SDK & a custom RSX render pipeline, Cerberus aims to implement Resident Evil's SeamlessHD Project on top of native PS1 emulation with dynamic QOL Improvements.

# Feature / Progress Roadmap
• CELL/SPE Optimised PCSX-Reloaded Implementation

• Dedicated 1080p MDEC Cutscene Processing

• SPE 5.1 Audio Processing

• Native HQ2X Scaling

• 50 to 120FPS Pacing

• RESHDP 1080p AI Upscaled Rooms/Mask & UI replacement

# Game QOL Improvements
• Adjustable 100% Dodge Mechanic Success

• Item / Enemy / Door Randomizer seeding

• Fast Nemesis - 2x, 4x & 8x Run speed

• UncappedNemmy - Sadistic Nemesis Spawns

# Future Plans
